# Statsviz v0.1.1

优化顶部操作区，让实时监控保留更多图表空间。

- 默认收起历史面板，顶部保留常用时间范围和“查看历史”入口。
- 点击“查看历史”后固定当前窗口，展开 1h / 6h / 24h / 7d、自定义起止时间、时间轴和采样详情。
- 缩放、平移图表或查看真实采样时自动展开历史面板。
- 点击“返回实时”后收起面板，恢复进入历史前的实时范围，并继续更新画面。
- 未启用历史的服务保持简洁，不显示历史入口和筛选。

升级：

```sh
go get github.com/PinableAgents/statsviz@v0.1.1
```

本次更新仅调整前端交互，已重新构建 Go 内嵌前端资源。
