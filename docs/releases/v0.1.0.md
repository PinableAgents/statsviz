# Statsviz v0.1.0

本版本增加基于 SQLite 的七天滚动历史。浏览器关闭后仍可采集，刷新页面或正常重启后可回看已落盘的指标。

## 新增能力

- 显式启用 `statsviz.History(store)`，使用纯 Go 的 `modernc.org/sqlite` 驱动，无需 CGO；数据库路径由接入方指定。
- 默认保留七天原始快照，异步批量写入，持久化10秒、1分钟、10分钟聚合。原始整数按原JSON保存，历史数据携带运行身份、配置、水位和缺口信息。
- 提供 `history/meta`、`history/range` 和 `history/point` 接口。
- 界面增加1h、6h、24h、7d、自定义起止时间、时间轴滑块、缩放和平移、真实时间点快照详情。固定历史视图期间继续采集，支持返回实时。

## 性能与可靠性

- 优化单点时间索引定位、运行尾部恢复和单运行概览的聚合主键读取。
- 聚合采用带版本的紧凑JSON格式；复制夹具中聚合payload减少69.2%。
- 关闭时只封存尚未完成的聚合桶，避免重复重写全部历史聚合。
- 优化入队校验分配，提前拒绝会使聚合失败的异常数值，保留原始整数字节。
- 加入显式启用的全量容量验收工具，验证604800条原始快照、完整默认指标、并发读写和正常关闭重开。

本机Apple M2、Go1.26.3、单运行523维合成数据实测：SQLite约4.85GiB，20轮含JSON编码的全局单点查询p95为0.366ms，七天概览p95为467.062ms。测量没有清理OS文件缓存；这些结果不代表生产环境或真实七天连续运行的性能承诺。完整条件和原始报告见[容量性能验收](https://github.com/PinableAgents/statsviz/blob/v0.1.0/docs/history-capacity-validation.md)。

## 使用与兼容

要求Go1.25或更新版本。安装：

```sh
go get github.com/PinableAgents/statsviz@v0.1.0
```

启用历史的完整接入和关闭顺序见[README](https://github.com/PinableAgents/statsviz/blob/v0.1.0/README.md#sqlite-history)，可运行的示例见[history](https://github.com/PinableAgents/statsviz/tree/v0.1.0/_example/history)。已有实时监控接入方式保持兼容。

历史库由一个采集进程持有。尚未提交的内存队列在异常退出时可能丢失；正常关闭会等待刷新。新程序可读取旧object聚合和新紧凑数组格式，较旧的历史实现无法读取新写入的紧凑聚合；降级前应保留数据库副本。SQLite会复用释放的页，滚动清理不意味着文件每日缩小。
