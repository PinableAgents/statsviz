# 需求说明

实现 Statsviz SQLite 七天滚动历史：异步快照存储、分层聚合、历史查询 API、时间轴与单点回看，完成测试和前端资源打包

## 背景与约束

用户已确认 SQLite 方案并要求完成编码。当前仓库为 Go 1.25 库与 Vite/Plotly 前端。持久化显式启用，独立适配器避免未使用者链接 SQLite；默认保存七天原始样本，长范围走聚合，前端支持历史时间轴与真实快照。保留旧 API 和自定义路由。当前工作区开发，不自动提交或推送。测试命令使用 `env -u GOROOT go ...`，避免本机错误的 GOROOT。Pinable 角色默认模型不可路由，本次调用使用本机 Codex 已配置的模型，不修改全局配置。

## 实现说明

1. 增加 `history` 公共契约和独立 `history/sqlite` 适配器，使用纯 Go SQLite 驱动；默认七天原始快照滚动保留、WAL、单写双读、文件所有权锁、有界异步队列、批量提交、缺口记录、恢复和关闭刷新。未导入适配器的原实时用户不链接 SQLite。
2. 采集生成不可变快照，HTTP 历史和 WS 共用同一份数值与身份；保存原始整数、run_id、seq 和单调 duration_ns。按子序列声明 gauge/rate/delta/histogram/event，持久化 10s/1m/10m 聚合；查询按预算继续加粗，边界逐级重算，避免全量扫描。
3. 根包增加 `statsviz.History(store)` 和 `Server.History()`，提供 meta/range/point、参数校验、两秒取消和响应预算；支持原有注册及自定义路由。Store 生命周期归调用方，Server.Close 停止生产后刷新。运行按最后已持久化序号封存，元数据读取设行数与字节上限。
4. 页面保留 1m/5m/10m 并增加 1h/6h/24h/7d、自定义起止、时间滑块、平移缩放、共享游标和真实单点详情；历史与暂停窗口冻结，支持返回实时。按运行配置和水位合并历史/WS 尾部，限制缓存，取消过时请求，直方图缺口明确标记。
5. 提供 `_example/history/main.go`、README、设计文档、SQL schema 与字段契约；修复 macOS ZIP 脚本并重新生成实际 Go 嵌入资源，逐文件验证与 dist 一致。
6. 最终验证通过：全仓 Go short/race/vet；linux/amd64、windows/amd64、darwin/arm64 的 CGO_ENABLED=0 构建；前端 33/33 与生产构建；真实 Chrome 嵌入页面 25 图、长预设、526 行旧运行详情、暂停预设、历史冻结、取消慢 point、返回实时和刷新，15 个历史 HTTP 全为 200、无 JS 错误。同一 SQLite 已重启到 run3，run1 仍可查询。
7. 性能边界：七天跨度 1007 聚合桶 × 523 维夹具返回 168 点、1h 粒度、811378 字节、单次 724ms；未据此宣称完整七天原始快照生产 p95 达标。固定端口 TestExamples 因已有 8080 服务未执行，采用 short 测试和独立端口示例验收。所有变更留在当前工作区，不自动提交、推送或发布。
